# AICO Genesis

Build the foundation of a production-ready enterprise corporate website for:

Advanced Imagination ITS Company (AICO)

Saudi Arabia

This is a premium global technology company website focused on:

Artificial Intelligence, Immersive Technology, Spatial Computing, Digital Transformation, Creative Technology, CGI, 3D Visualization and Immersive Media.

IMPORTANT:

Do not create a simple landing page.

Build a scalable multi-page corporate website architecture that can grow for years.

DESIGN DIRECTION:

Create a premium, sophisticated, futuristic corporate design inspired by the quality level of companies such as Microsoft, NVIDIA, IBM, Accenture, Palantir, Apple and OpenAI.

Do NOT copy their branding.

The visual identity should be:

- Premium

- Minimal

- Elegant

- Futuristic

- Corporate

- Technological

- Immersive

- High-end

COLOR SYSTEM:

Primary Blue:

#082A8C

Accent Red:

#E30613

Dark Background:

#050B24

White:

#FFFFFF

Use a sophisticated gray scale.

TYPOGRAPHY:

Use:

Inter

Space Grotesk

Create a responsive typography system.

Create these main routes:

/

 /who-we-are

 /industries

 /our-approach

 /technology-ecosystem

 /immersive-content-studio

 /insights

 /contact

GLOBAL NAVIGATION:

Create a premium responsive header.

Navigation:

Who We Are

Industries

Solutions

Our Approach

Technology Ecosystem

Studio

Insights

Contact

Solutions should have a professional dropdown/mega-menu.

Include a clear primary CTA.

Create a premium mobile navigation.

HOME PAGE:

Build a high-end hero section with:

- Large typography

- Dark technology-focused background

- Subtle blue/red light effects

- Elegant gradients

- Very subtle particles

- Sophisticated motion

- Strong visual hierarchy

- Primary CTA

- Secondary CTA

The hero must communicate that AICO is a technology and innovation company.

HOME PAGE SECTIONS:

1. Hero

2. Who We Are

3. Core Capabilities

4. Solutions

5. Industries

6. Technology Ecosystem

7. Immersive Content Studio

8. Selected Work / Projects

9. Partners

10. Insights

11. Final CTA

12. Footer

Do not invent real clients, partners, projects, awards, certifications, statistics or business achievements.

If company information is unavailable, create clean editable content structures that can later be replaced.

UI SYSTEM:

Create reusable components for:

- Buttons

- Cards

- Badges

- Section headers

- Containers

- Navigation

- Mobile navigation

- Forms

- Modals

- Gallery

- Tabs

- Accordions

- Footer

- CTA sections

RESPONSIVE:

The website must work perfectly on:

- Desktop

- Laptop

- Tablet

- Mobile

No horizontal scrolling.

Use excellent spacing and responsive typography.

ANIMATION:

Use subtle premium animations.

Include:

- Fade

- Reveal

- Slide

- Scale

- Hover interactions

- Scroll reveal

- Parallax where appropriate

Do not overuse animations.

Respect prefers-reduced-motion.

IMAGES:

Do not use Base64 images.

Create the following image structure:

public/images/home

public/images/solutions

public/images/studio

public/images/gallery

public/images/partners

Use replaceable image paths.

If real AICO images are not available, use neutral abstract technology visuals or elegant placeholders.

Do not falsely present stock imagery as AICO projects.

CODE ARCHITECTURE:

Use a clean scalable architecture.

Separate:

- Components

- UI

- Sections

- Data

- Types

- Utilities

- Hooks

Business content should be stored separately from UI components.

Create structured data models for:

- Solutions

- Industries

- Projects

- Partners

- Insights

- Company information

Do not hardcode repeated content inside components.

ACCESSIBILITY:

Use:

- Semantic HTML

- Proper heading hierarchy

- Keyboard navigation

- Accessible buttons

- ARIA labels where necessary

- Visible focus states

- Accessible forms

- Alt text

SEO:

Prepare the architecture for:

- Page metadata

- Open Graph

- Twitter/X cards

- Sitemap

- Robots

- Structured data

PERFORMANCE:

Prioritize:

- Image optimization

- Lazy loading

- Code splitting

- Dynamic loading for heavy components

- Minimal client-side JavaScript

- Fast page loading

IMPORTANT:

Do not build only a visual mockup.

Create a real multi-page website structure with working navigation and reusable components.

Make the architecture easy to extend with additional pages, solutions, projects, insights and future integrations.

Before finishing, verify that all routes work and that the website is responsive.
